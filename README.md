# 井尻有輝 パフォーマンス LP（身体能力チェック・体験トレーニング獲得用）

愛知県安城市のパーソナルトレーナー「井尻有輝」個人の専門性を軸にしたLP。
「安城で身体能力を上げたいなら井尻」という第一想起の獲得と、
**身体能力チェック（最重要CV）／体験トレーニング（次点CV）**への申込みを目的に設計。

ブランド構造：Mintea's（幅広い人向けパーソナルジム）＞ 井尻有輝（身体能力・パフォーマンス向上の専門家）の二階建て。

## 7. 今後ABテストすべき項目 3つ

1. **ファーストビューの見出し**：現行の「もっと動ける。もっと、できる。」（能力向上の期待感訴求）と、「競技練習だけでは身につかない、身体そのものの能力を。」（課題直球訴求）を比較し、身体能力チェック申込率への影響を検証する。
2. **ジュニアセクションの並び順**：現行は「ジュニア→一般→アスリート」の順（最重要ターゲットを最初に配置）。保護者の不安解消（target-callout）を先に出すパターンと、悩み訴求（target-lead）を先に出すパターンを比較する。
3. **身体能力チェックの見せ方**：現行は「STEP1〜4」の測定フロー訴求。これに加えて「何が分かるか（強み／課題のフィードバック内容）」をより具体的に見せるパターンと比較し、申込率への影響を検証する。

## 10-α. マーケティングリサーチの反映内容

`~/Downloads/LP作成マーケティング重要項目リサーチ.pdf`（CXL・Think with Google・国内CRO専門メディア等を出典とするCRO調査）を参照し、以下を反映しました。

| リサーチの指摘 | 本LPでの対応 |
|---|---|
| メッセージマッチ：Instagram等の流入元と訴求を一致させる | Instagramからの流入を前提に、初めて井尻を知る人でも理解できる構成・文言に統一（`CLAUDE.md`要件と一致） |
| ファーストビューは「CTAを置く場所」より「読む価値を示す入口」。false bottom（終わった感）を避け、続きを示唆する | ヒーロー下部に "Scroll ↓" のスクロール誘導サインを追加。悩み訴求（SYMPTOM）へ自然につながる構成に |
| CTAは色より視認性・コントラスト・マイクロコピーが重要 | 最終CTA横の「電話で相談する／LINEで相談する」ボタンが背景と同化して読めない実装バグを検出・修正。CTA文言も「身体能力チェックを体験する」と行動＋対象を明確化 |
| 社会的証明は導入率が低い一方で効果が大きい。ただし個別事例の数値は自社に当てはまる保証はない | 口コミ・改善率などの**架空の数値は一切追加せず**（捏造禁止ルール優先）、代わりに「体験者の声・改善事例は準備中」という正直な告知＋Instagramへの導線を追加し、信頼構築の空白を透明性でカバー |
| CTAは根拠提示の直後など複数箇所に配置する | ヘッダー／FV／ジュニア・一般・アスリート各セクション末尾／最終CTA／スマホ固定バーに配置済み（文言は統一） |
| ページ速度・モバイル対応 | 画像はJPEG圧縮済み実写のみ使用、hero画像のみ`fetchpriority="high"`、以降は`loading="lazy"`。CSS/JSは各1ファイルのみでレンダリングパスを単純化 |
| A/Bテストは最低2週間・十分なサンプルサイズで検証し、影響の大きい要素から着手する | 「7. 今後ABテストすべき項目」に、FV見出し／セクション構成／訴求の見せ方というインパクトの大きい要素を優先して記載 |

※本リサーチ内の個別改善率（CVR+○%等）は業種・母数の異なる他社事例であり、本LPに同じ効果を保証するものではないため、数値そのものは本LP上に転記していません。公開後は必ず自社データでのA/Bテストによる検証を推奨します。
